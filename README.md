# 脑腐指数测试 · Brain Rot Index

娱乐向自测网站：首页 → 随机20题 → 五维分析与段位 → 本地分享图。
保留原来的深紫霓虹风格、5个维度、8个段位与20—60分区间。无后端、登录或付费。

## 2026-10-20 本次优化

- 题库由20题扩充为60题，每个维度12题；每轮仍答20题。
- 每个维度随机抽4题，再打乱全轮题序；一轮内不重复。
- 重新抽题优先使用上一轮未出现的题，目前的题库容量可以保证相邻两轮不重复。
- 三个选项也会洗牌，答案按“题目ID → 原始选项下标”保存，不依赖显示的A/B/C。
- 保存抽中的题目、题序、选项顺序、答案与当前位置。刷新和返回首页后继续同一轮。
- 未完成时首页提供“继续上次测试”和需确认的“重新抽题”；上次完成的结果独立保留。
- 首次选择自动前进，返回修改后停留；同步锁覆盖自动跳题和切题阶段，避免连点跳过题目。
- 非法选项、缺题、重复或维度不平衡的题组都不能产生正式结果；本轮以外的答案不参与计分。
- 旧20题答案按原题组、原选项顺序迁移，恢复到首个未答题；旧结果按真实维度分数安全重建。
- 存储不可用时本轮仍能在页面内完成，但会提示刷新/关闭后可能丢失，不再假称保存成功。
- 同分结果明确显示一致/含同分，并覆盖所有相关维度的建议；分享图0%进度不再画出彩色短条。

## 随机与计分规则

随机只用于抽题和排列，不参与决定段位或补造分数。每次抽题使用Fisher–Yates洗牌：
各维度先抽4题，合计20题，再整体洗牌；选项排列同时固定在本轮会话中。

每题的原始三个选项分别为1、2、3分。显示顺序变化时，按原始选项下标查分：
**不能把A固定当1分、C固定当3分。**

- 总分 = 本轮20题得分之和，范围20—60。
- 脑腐进度 = (总分 − 20) ÷ 40 × 100%，保留一位小数。
- 维度得分 = 本轮该维度4题的得分之和，范围4—12。
- 维度进度 = (维度得分 − 4) ÷ 8 × 100%，四舍五入取整。
- 段位区间依次为20—24、25—29、30—34、35—39、40—44、45—49、50—54、55—60。
- 得分靠前的两个维度用于解释；第二名有同分时同时列出相关维度。五维完全同分时明确说明得分一致。
- 同一题组和同一份有效答案得到相同分数、段位与解释；生成日期独立记录。
- 不同轮次抽到的题不同，结果只作娱乐参考，没有宣称经过标准化或心理学验证。

## 怎样修改题库

在 `questions.ts` 中为每道题保留唯一ID、有效维度、情境、题干和三个选项：

```ts
{
  id: 61,
  dimension: 'attention',
  scene: '你的生活情境',
  title: '一个清楚的问题',
  options: [
    { text: '程度较低的合理反应', score: 1 },
    { text: '程度中等的合理反应', score: 2 },
    { text: '程度较高的合理反应', score: 3 },
  ],
}
```

保留已有ID的含义，不把旧答案套到新问题上。修改已存在题目的含义或分值时，要同步更新题库版本。
每个维度至少要有4题；建议均衡增加五维题库。只扩充题库时，不改变每轮20题或段位区间。

新增题的内容包括课堂休息、课程展示、小组安排、食堂用餐、通勤、评论互动、资料检索等情境。
页面选项由会话的 `optionOrders` 展示，计分始终查原始选项。

## 保存与兼容

- 新会话键：`brainrot.session.v2`，含题库版本、选题ID、选项排列、答案、当前位置、开始时间及可选的正式提交时间。
- 阶段键：`brainrot.stage.v1`。
- 最近结果键：`brainrot.result.v1`，保留有效旧记录和原日期，按当前配置校验并重建显示数据。
- 仅在没有新版会话时读取 `brainrot.answers.v1` 进行旧轮次迁移；不删除原记录。
- 已有新版会话损坏或题库版本不匹配时回到安全入口，不能临时换题继续套旧答案。
- 浏览器禁止保存时，React中的当前会话仍支持答题、切页、结果和导出；无法承诺刷新后恢复。
