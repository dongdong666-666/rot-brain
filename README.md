- 旧20题答案按原题组、原选项顺序迁移，恢复到首个未答题；旧结果按真实维度分数安全重建。

## 随机与计分规则

随机只用于抽题和排列，不参与决定段位或补造分数。每次抽题使用Fisher–Yates洗牌：
各维度先抽4题，合计20题，再整体洗牌；选项排列同时固定在本轮会话中。

每题的原始三个选项分别为1、2、3分。显示顺序变化时，按原始选项下标查分：
**不能把A固定当1分、C固定当3分。**

- 总分 = 本轮20题得分之和，范围20—60。
- 脑腐进度 = (总分 − 20) ÷ 40 × 100%，保留一位小数。
- 维度得分 = 本轮该维度4题的得分之和，范围4—12。
- 维度进度 = (维度得分 − 4) ÷ 8 × 100%，四舍五入取整。
- 段位区间依次为20—24、25—29、30—34、35—39、40—44、45—49、50—54、55—60。
- 得分靠前的两个维度用于“突出维度”展示；第二名有同分时同时列出相关维度。五维完全同分时明确说明得分一致。
- 建议与“突出维度”是两件事：突出维度只做展示，建议按各维度得分的分层单独挑选，两者不互相替代。
- 同一题组和同一份有效答案得到相同分数、段位与解释；生成日期独立记录。
- 不同轮次抽到的题不同，结果只作娱乐参考，没有宣称经过标准化或心理学验证。

## 怎样修改题库

在 `questions.ts` 中为每道题保留唯一ID、有效维度、情境、题干和三个选项：

```ts
{
  id: 61,
  dimension: 'attention',
  scene: '你的生活情境',
  title: '一个清楚的问题',
  options: [
    { text: '程度较低的合理反应', score: 1 },
    { text: '程度中等的合理反应', score: 2 },
    { text: '程度较高的合理反应', score: 3 },
  ],
}
```

保留已有ID的含义，不把旧答案套到新问题上。修改已存在题目的含义或分值时，要同步更新题库版本。
每个维度至少要有4题；建议均衡增加五维题库。只扩充题库时，不改变每轮20题或段位区间。

新增题的内容包括课堂休息、课程展示、小组安排、食堂用餐、通勤、评论互动、资料检索等情境。
页面选项由会话的 `optionOrders` 展示，计分始终查原始选项。

## 保存与兼容
